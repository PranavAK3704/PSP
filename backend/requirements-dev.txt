# Development-only dependencies. NOT installed in the image: the Dockerfile installs
# requirements.txt alone, and a test framework has no business in a production container.
#
# This file exists because the repo had NO test suite and no test dependency at all before
# app/intake/ — so there was no convention to follow here, only one to start. The intake
# pipeline's correctness rests on fixtures that assert exact token sets (every regex error in
# this project produced a plausible COUNT and was caught only by printing the tokens), so its
# tests are load-bearing rather than decorative.
#
#   .venv/bin/python -m pip install -r requirements-dev.txt
#   .venv/bin/python -m pytest tests/intake -q
#
# The repo-native harness `scripts/check_intake.py` runs the same invariants with no third-party
# dependency at all, and is registered in scripts/check_all.py. Either one alone is enough to
# catch a regression; pytest is the one that reports which assertion failed.
pytest==8.3.4
